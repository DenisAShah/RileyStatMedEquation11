# RileyStatMedEquation11
Rearrangement of Equation 11 in [Riley et al. (2021). Minimum sample size for external validation of a clinical prediction model with a binary outcome. Statistics in Medicine. 40:4230–4251.](https://onlinelibrary.wiley.com/doi/full/10.1002/sim.9025)

This repository contains a preliminary version of the code, which is further expanded upon and presented here: [Shah et al. (2026). A note on closed-form solutions for estimating sample size when externally validating a binary prediction model based on *C*-statistic precision. arXiv eprint 2605.23664](https://arxiv.org/abs/2605.23664).

The code version linked to the arXiv eprint is hosted on Zenodo: https://doi.org/10.5281/zenodo.15850396.
Please refer to that Zenodo record for reproduction and citation.
